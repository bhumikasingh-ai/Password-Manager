# 🔐 Password Manager

A simple and beginner-friendly **Password Manager built with Python**.

This project allows users to generate, save, view, search, edit, and delete passwords. It also includes a password strength checker.

## ✨ Features

- 🔑 Generate strong random passwords
- 💾 Save passwords locally
- 👀 View saved passwords
- 🔍 Search passwords
- ✏️ Edit saved passwords
- 🗑️ Delete passwords
- 🛡️ Check password strength

## 🛠️ Technologies Used

- Python 3
- JSON
- `secrets` module
- `string` module
- `os` module

## ▶️ How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python password-management.py
```

## 📋 Main Menu

1. Generate Password
2. Save Password
3. View Passwords
4. Delete Password
5. Search Password
6. Edit Password
7. Check Password Strength
8. Exit
